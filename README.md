# Autonomous Agents

Guidance for building autonomous AI agents that plan, use tools, execute tasks, and manage multi-step workflows.

## Features

- Domain-focused workflows and implementation guidance.
- Practical patterns and examples.
- Best practices and validation considerations.

## Installation

Copy the skill into your agent skills directory:

```bash
mkdir -p .claude/skills/autonomous-agents
cp SKILL.md .claude/skills/autonomous-agents/SKILL.md
```

## Usage

Ask your AI coding assistant to use **Autonomous Agents** for a related task and follow the instructions in `SKILL.md`.
